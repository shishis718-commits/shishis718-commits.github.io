如何更新这里

这是一份静态网站，目前没有内置登录式后台。你可以自己在 GitHub 编辑，也可以把内容和照片发给我，我帮你整理并提交。

最省事的方法：把文章文字、照片和要放进的板块发到 ChatGPT，告诉我标题、日期和分类，我可以帮你更新网站。你不需要自己写代码。

方法一：让我帮你发布

你可以直接发一条消息，例如：

“把这篇读后感发布到书影音，标题是……日期是……正文如下……”

发布照片时，把图片发给我，并告诉我放在「日常生活」照片墙，配文和日期是什么。我会帮你上传图片、更新页面并提交到 GitHub。

方法二：自己通过 GitHub 发布文字

STEP 01

打开对应页面

进入仓库 shishis718-commits.github.io，打开 daily.html、culture.html、fanworks.html 或 interests.html。

STEP 02

点击编辑

点击文件右上角铅笔图标，找到示例卡片，复制一份并替换标题、日期和正文。不要删掉页面其他结构。

STEP 03

提交修改

点击页面右上角 Commit changes，填写简短说明，再确认提交到 main 分支。

STEP 04

等待网站更新

GitHub Pages 通常会自动重新发布。稍等片刻刷新网站即可看到新内容。

如何发布照片

1. 在仓库里进入 assets 文件夹，再进入或新建 uploads 文件夹。

2. 点击 Add file → Upload files，选择手机或电脑里的照片，提交修改。

3. 打开 daily.html，找到照片墙，把示例占位卡片替换为下面的图片代码：

<figure class="photo-item">
  <img src="assets/uploads/你的照片.jpg" alt="照片描述">
  <figcaption>2026.11.13 · 今天的照片</figcaption>
</figure>

文件名尽量使用英文、数字和短横线，例如 autumn-walk-01.jpg。照片过大时先压缩一下。视频建议使用外部平台链接或嵌入，不要直接往 GitHub 仓库上传大型视频。

发布前要知道

• 这是公开网站，任何人都可能看到你发布的文字和图片。

• 目前没有访客留言后台、自动图片上传表单或在线富文本编辑器。

• GitHub 网页端可以直接编辑文件；如果你想要像微信公众号那样点“新建文章”、选图片、点“发布”，以后可以再接入独立 CMS 后台。
